# Web de prueba del asistente de Rikuy

Página estática (GitHub Pages) que simula la web propia de un municipio para probar el asistente de [Rikuy](https://github.com/jorgesolizvidal/rikuy) insertado con una línea de script (ADR-071, «Solo asistente»).

No es la web oficial de ningún municipio. El botón solo aparece si el operador de Rikuy autorizó el origen `https://jorgesolizvidal.github.io` para ese municipio.
